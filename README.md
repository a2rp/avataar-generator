# Avataar Generator

Avataar Generator is a React workspace for creating, customizing, saving, and exporting DiceBear avatars.

![Avataar Generator screenshot](screenshot.png)

## Features

- 31 DiceBear avatar styles with searchable previews
- Custom seeds with previous and next variant navigation
- Scale, rotation, radius, margin, flip, and background controls
- Favorites saved in local browser storage
- PNG, SVG, Data URI, and configuration export tools
- Light and dark themes
- Responsive layout with keyboard-friendly controls

## Tech Stack

- React
- Vite
- JavaScript
- styled-components
- DiceBear
- React Icons

## Run Locally

```bash
git clone https://github.com/a2rp/avataar-generator.git
cd avataar-generator
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

Preview the build locally with:

```bash
npm run preview
```
